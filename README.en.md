## What is ManJu Creator?

ManJu Creator is a Claude Code Skill for planning AI-generated video. It converts a creative brief into deliberate camera language, visual style, scene structure, and production-ready prompts instead of relying on a single unstructured sentence.

## Core capabilities

- Camera movement and shot-language guidance
- Visual style selection and parameter mapping
- Five-dimensional prompt construction
- Storyboard planning for multi-shot sequences
- Reusable prompt templates and reference libraries
- Examples for cinematic, animated, cyberpunk, and noir directions

## Installation

Clone the repository and copy it into your Claude Code skills directory:

```bash
git clone https://github.com/rfdiosuao/Yuhang-ManJu.git manju-creator
cp -r manju-creator ~/.claude/skills/
```

Then ask Claude Code to use the ManJu Creator Skill for an AI-video prompt or storyboard task.

## Suggested workflow

1. Define the subject, action, setting, and emotional goal.
2. Choose the shot size, camera movement, lens feeling, and composition.
3. Select a visual style and lighting direction.
4. Build a timed shot list or a single structured prompt.
5. Review continuity, feasibility, safety, and model-specific constraints.

## Responsible use

Review generated prompts before production. Respect image rights, performer consent, trademarks, model-provider policies, and local laws. Do not use the workflow for deceptive impersonation or unauthorized likeness generation.
