## 📷 一、基础镜头运动（10 种）

### 1. 推镜头 (Dolly In / Push In)
**定义：** 镜头向前推进，逐渐靠近主体
**效果：** 突出主体、增强情绪、引导注意力
**适用场景：** 
- 揭示重要细节
- 强调角色情绪
- 制造紧张感
**提示词示例：** `slow dolly in, pushing towards subject, gradual zoom in`

### 2. 拉镜头 (Dolly Out / Pull Back)
**定义：** 镜头向后拉远，逐渐远离主体
**效果：** 展示环境、揭示全貌、产生距离感
**适用场景：**
- 揭示场景全貌
- 结束场景
- 表现孤独感
**提示词示例：** `pull back, dolly out, revealing wider context`

### 3. 摇镜头 (Pan)
**定义：** 镜头水平旋转，左右转动
**效果：** 展示空间、跟随运动、连接场景
**适用场景：**
- 展示宽阔场景
- 跟随横向运动
- 环境介绍
**提示词示例：** `pan left, horizontal pan, sweeping view`

### 4. 移镜头 (Truck / Track)
**定义：** 镜头水平移动，平行于主体
**效果：** 跟随运动、展示侧面、保持距离
**适用场景：**
- 跟随行走的人物
- 展示建筑侧面
- 平行运动
**提示词示例：** `tracking shot, lateral movement, parallel follow`

### 5. 跟镜头 (Follow)
**定义：** 镜头跟随主体运动
**效果：** 增强代入感、保持联系、动态视角
**适用场景：**
- 追逐场景
- 行走对话
- 运动场景
**提示词示例：** `following shot, tracking subject, moving with character`

### 6. 升镜头 (Crane Up / Boom Up)
**定义：** 镜头垂直上升
**效果：** 展示高度、俯瞰全景、提升视角
**适用场景：**
- 揭示场景规模
- 表现角色渺小
- 建立镜头
**提示词示例：** `crane up, rising camera, ascending view`

### 7. 降镜头 (Crane Down / Boom Down)
**定义：** 镜头垂直下降
**效果：** 聚焦主体、降低视角、接近地面
**适用场景：**
- 从高处聚焦角色
- 展示地面细节
- 降落感
**提示词示例：** `crane down, descending camera, lowering view`

### 8. 甩镜头 (Whip Pan)
**定义：** 快速摇镜头，产生模糊效果
**效果：** 转场、快速切换、增强动感
**适用场景：**
- 快速转场
- 动作场景
- 紧急情况
**提示词示例：** `whip pan, fast pan, rapid camera movement`

### 9. 变焦镜头 (Zoom)
**定义：** 焦距变化，放大或缩小
**效果：** 改变视角、强调细节、制造压迫感
**适用场景：**
- 突然发现
- 心理压迫
- 视觉冲击
**提示词示例：** `zoom in, zoom out, focal length change`

### 10. 旋转镜头 (Roll / Rotation)
**定义：** 镜头绕光轴旋转
**效果：** 迷幻效果、表现混乱、特殊视觉
**适用场景：**
- 表现眩晕
- 特殊效果
- 梦境场景
**提示词示例：** `camera roll, rotating view, spinning shot`

## 🎬 二、进阶镜头技巧（6 种）

### 1. 第一人称视角 (POV / First Person)
**定义：** 以角色眼睛为视角
**效果：** 强代入感、沉浸体验、主观视角
**适用场景：**
- 恐怖片
- 动作游戏
- 主观体验
**提示词示例：** `POV shot, first person view, through character's eyes`

### 2. 俯拍 (High Angle / Bird's Eye)
**定义：** 从高处向下拍摄
**效果：** 表现渺小、弱势、全局视角
**适用场景：**
- 表现角色弱势
- 展示场景布局
- 上帝视角
**提示词示例：** `high angle shot, bird's eye view, overhead shot`

### 3. 仰拍 (Low Angle / Worm's Eye)
**定义：** 从低处向上拍摄
**效果：** 表现高大、强势、威严
**适用场景：**
- 表现角色强大
- 建筑宏伟
- 英雄形象
**提示词示例：** `low angle shot, worm's eye view, looking up`

### 4. 荷兰角 (Dutch Angle / Tilted)
**定义：** 镜头倾斜，不水平
**效果：** 不安、紧张、混乱
**适用场景：**
- 心理惊悚
- 表现不安
- 特殊效果
**提示词示例：** `dutch angle, tilted frame, canted angle`

### 5. 过肩镜头 (Over the Shoulder)
**定义：** 越过一个角色的肩膀拍摄另一个角色
**效果：** 对话场景、建立关系、空间感
**适用场景：**
- 对话场景
- 两人互动
- 建立空间关系
**提示词示例：** `over the shoulder shot, OTS, behind character`

### 6. 蒙太奇 (Montage)
**定义：** 快速剪辑多个镜头
**效果：** 时间压缩、信息密集、节奏感
**适用场景：**
- 时间流逝
- 训练过程
- 多线叙事
**提示词示例：** `montage sequence, rapid cuts, multiple shots`

## 📐 三、景别分类

| 景别 | 英文 | 描述 | 适用场景 |
|------|------|------|----------|
| 极远景 | Extreme Long Shot | 主体很小，环境为主 | 建立场景、史诗感 |
| 远景 | Long Shot | 主体完整，环境明显 | 场景展示、人物位置 |
| 全景 | Full Shot | 人物全身可见 | 动作展示、服装展示 |
| 中景 | Medium Shot | 膝盖以上 | 对话、日常场景 |
| 中近景 | Medium Close-Up | 胸部以上 | 对话、表情 |
| 近景 | Close-Up | 肩膀以上 | 表情、情绪 |
| 特写 | Close-Up | 面部为主 | 情绪强调、细节 |
| 大特写 | Extreme Close-Up | 局部特写 | 极度强调、细节展示 |

## 🎯 四、镜头组合技巧

### 情绪递进组合
```
全景（建立场景）→ 中景（展示人物）→ 近景（情绪铺垫）→ 特写（情绪高潮）
```

### 动作展示组合
```
远景（动作全貌）→ 中景（动作细节）→ 特写（关键瞬间）→ 全景（动作结果）
```

### 对话场景组合
```
中景（两人同框）→ 过肩镜头（对话交替）→ 近景（情绪反应）→ 特写（关键时刻）
```

### 紧张氛围组合
```
中景（正常视角）→ 荷兰角（不安感）→ 特写（紧张情绪）→ 快速剪辑（高潮）
```

## 📋 五、镜头语言提示词模板

### 基础模板
```
[景别] + [镜头运动] + [视角] + [主体描述]

示例：
中景 + 缓慢推进 + 平视 + 角色表情变化
```

### 完整模板
```
[景别] shot, [镜头运动], [视角] angle, [主体描述], [运动方向], [速度]

示例：
Medium shot, slow dolly in, eye level, character's face showing determination, moving forward, gradual pace
```

### 视频生成专用
```
Stage 4 [镜头 1.1]: ([景别], [镜头运动], [视角], [速度])

示例：
Stage 4: (中景，缓慢推进，平视，缓慢节奏:1.1)
```

## 🔧 六、镜头选择指南

| 场景类型 | 推荐镜头 | 避免镜头 |
|----------|----------|----------|
| 情感对话 | 中景、近景、过肩 | 远景、甩镜头 |
| 动作场景 | 全景、跟镜头、快速剪辑 | 固定长镜头 |
| 恐怖场景 | POV、荷兰角、特写 | 明亮全景 |
| 产品展示 | 特写、推镜头、旋转 | 甩镜头 |
| 风景展示 | 远景、摇镜头、升镜头 | 特写 |
| 角色介绍 | 全景→中景→近景 | 直接特写 |
