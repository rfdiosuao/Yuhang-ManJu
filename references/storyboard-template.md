## 📝 二、列说明

### 1. 镜头号
- 格式：数字编号（1, 2, 3...）
- 作用：标识镜头顺序
- 示例：1, 2, 3, 4...

### 2. 景别
- 选项：极远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- 作用：确定画面范围
- 示例：特写、全景、中景

### 3. 镜头运动
- 选项：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 甩 / 变焦 / 旋转
- 作用：确定镜头动态
- 示例：缓慢推进、快速摇镜头、固定

### 4. 时长
- 格式：**强制 10s**
- 作用：确定镜头持续时间
- 规则：**每个镜头必须固定为 10 秒，禁止使用其他时长**

### 5. 画面内容
- 内容：详细描述画面中的所有元素
- 要求：具体、可执行
- 示例：李玄风的眼睛猛然睁开，瞳孔收缩，机械义眼发出红色光芒

### 6. 对白/音效
- 内容：角色对白或环境音效
- 格式：对白用引号，音效用括号
- 示例："这是...什么？" / （心跳声、仪器滴答声）

### 7. 光影/色调
- 内容：光源方向、强度、色温、色调
- 示例：冷色调，蓝色主光，侧面光 / 暖色调，金色阳光，逆光

### 8. 角色
- 内容：本镜头出现的角色
- 示例：李玄风 / 李玄风、医生

### 9. 道具/特效
- 内容：道具、特效、动画元素
- 示例：机械义眼、光剑 / 速度线、粒子效果

### 10. 备注
- 内容：特殊要求、注意事项
- 示例：机械义眼红光闪烁 / 注意角色一致性

## 🎯 四、分镜设计原则

### 1. 时长控制
- **强制规则：每个镜头必须固定为 10 秒**
- 总时长：按镜头数量计算（如 3 个镜头 = 30s）
- 禁止使用其他时长参数

### 2. 景别变化
- 避免连续相同景别
- 大小景别交替使用
- 情绪高潮用特写

### 3. 镜头运动
- 有目的的运动，避免无意义晃动
- 运动速度与情绪匹配
- 静态镜头与动态镜头结合

### 4. 光影连贯
- 同一场景保持光源一致
- 情绪变化可调整光影
- 注意角色光影方向

### 5. 角色一致性
- 每个镜头确认角色外貌
- 服装、发型保持一致
- 标志性元素不丢失
