## 🎬 一、电影感风格 (Cinematic)

### 1.1 写实电影风 (Cinematic Realism)
**英文标识：** `cinematic realism, photorealistic`
**核心特征：** 胶片质感 / 自然光影 / 真实纹理 / 电影调色
**代表参数：**
- 色调：Kodak 2383 胶片模拟，轻微暖调
- 光影：自然光源优先，柔和过渡
- 质感：皮肤纹理/布料褶皱/环境细节清晰
**适用场景：** 人像写真、剧情短片、纪录片风格
**负面提示词：** `cartoon, anime, cgi, 3d render, plastic skin`

### 1.2 王家卫风格 (Wong Kar-wai Style)
**英文标识：** `wong kar wai style, stephen wong cinematography`
**核心特征：** 高饱和暖色 / 运动模糊 / 霓虹光影 / 情绪化构图
**代表参数：**
- 色调：橙青色调 (teal & orange)，高饱和
- 光影：霓虹灯/路灯/烛光，强对比
- 质感：轻微颗粒感，motion blur
**适用场景：** 情绪人像、都市夜景、浪漫剧情
**负面提示词：** `flat lighting, neutral colors, sharp focus, documentary`

### 1.3 Wes Anderson 风格
**英文标识：** `wes anderson style, symmetrical composition`
**核心特征：** 对称构图 / 粉彩配色 / 平面化 / 复古美学
**代表参数：**
- 色调：粉彩 pastel colors (粉/蓝/黄/绿)
- 光影：均匀柔光，低对比
- 质感：平面化，minimal shadows
**适用场景：** 创意广告、品牌视觉、艺术短片
**负面提示词：** `asymmetrical, dark shadows, high contrast, gritty`

### 1.4 诺兰暗黑风 (Nolan Dark Cinematic)
**英文标识：** `nolan style, dark cinematic, imax quality`
**核心特征：** 低照度 / 高对比 / 冷色调 / IMAX 质感
**代表参数：**
- 色调：冷蓝/青灰色，desaturated
- 光影：硬光，deep shadows，practical lights
- 质感：IMAX 胶片颗粒，ultra sharp
**适用场景：** 科幻、悬疑、动作大片
**负面提示词：** `bright, colorful, soft lighting, cheerful`

### 1.5 赛博朋克电影风 (Cyberpunk Cinematic)
**英文标识：** `cyberpunk, blade runner style, neon noir`
**核心特征：** 霓虹光影 / 高饱和对比 / 雨夜氛围 / 未来都市
**代表参数：**
- 色调：紫/蓝/粉霓虹，dark background
- 光影：neon signs, volumetric fog, wet surfaces
- 质感：反光表面，rain drops
**适用场景：** 科幻场景、概念设计、MV
**负面提示词：** `daylight, natural lighting, pastoral, clean`

## 🎨 二、艺术风格 (Artistic)

### 2.1 油画风格 (Oil Painting)
**英文标识：** `oil painting, classical art`
**核心特征：** 厚涂笔触 / 色彩层次 / 画布纹理 / 古典质感
**适用场景：** 艺术创作、肖像画、风景画
**负面提示词：** `photorealistic, smooth, digital art, vector`

### 2.2 水彩风格 (Watercolor)
**英文标识：** `watercolor painting, aquarelle`
**核心特征：** 透明晕染 / 留白 / 流动感 / 轻盈
**适用场景：** 插画、儿童绘本、清新风格
**负面提示词：** `opaque, thick, sharp edges, photorealistic`

### 2.3 浮世绘风格 (Ukiyo-e)
**英文标识：** `ukiyo-e, japanese woodblock print`
**核心特征：** 平面化 / 粗轮廓线 / 纯色块 / 日式美学
**适用场景：** 日式主题、文化创作、装饰画
**负面提示词：** `3d, shading, gradient, western art`

### 2.4 印象派风格 (Impressionism)
**英文标识：** `impressionism, monet style, renoir style`
**核心特征：** 短促笔触 / 光色变化 / 朦胧感 / 户外光影
**适用场景：** 风景、光影研究、艺术创作
**负面提示词：** `sharp focus, smooth, studio lighting, precise`

## 🌆 三、现代风格 (Modern)

### 3.1 极简商业风 (Minimalist Commercial)
**英文标识：** `minimalist, commercial photography, clean`
**核心特征：** 留白 / 纯色背景 / 主体突出 / 高级感
**适用场景：** 产品摄影、品牌视觉、电商主图
**负面提示词：** `cluttered, busy background, dramatic shadows, grunge`

### 3.2 国潮风格 (Chinese Trendy / Guochao)
**英文标识：** `guochao, chinese trendy, neo-chinese style`
**核心特征：** 传统元素 / 现代演绎 / 高饱和 / 文化自信
**代表参数：**
- 色调：china red, gold, jade green
- 光影：dramatic, stylized
- 质感：mix of traditional patterns + modern design
**适用场景：** 国货品牌、文化活动、节日营销
**负面提示词：** `western style, muted colors, traditional only`

### 3.3 蒸汽波风格 (Vaporwave)
**英文标识：** `vaporwave, aesthetic, retro futurism`
**核心特征：** 复古未来 / 粉紫配色 / 古典雕塑 / 80s 美学
**适用场景：** 音乐视觉、创意海报、亚文化
**负面提示词：** `realistic, natural colors, modern, clean`

### 3.4 酸性设计风格 (Acid Graphics)
**英文标识：** `acid graphics, y2k aesthetic, chrome`
**核心特征：** 金属质感 / 荧光色 / 液态形态 / 未来感
**适用场景：** 音乐海报、潮流品牌、Z 世代营销
**负面提示词：** `matte, earth tones, traditional, conservative`

## 🎭 四、二次元风格 (Anime & Illustration)

### 4.1 日漫风格 (Japanese Anime)
**英文标识：** `japanese anime, manga style, studio ghibli`
**核心特征：** 大眼睛 / 简化五官 / 赛璐璐上色 / 线条清晰
**适用场景：** 角色设计、动画概念、插画
**负面提示词：** `realistic, 3d, oil painting, sketchy`

### 4.2 3D 国漫玄幻风格 (3D Chinese Fantasy)
**英文标识：** `3d-chinese-fantasy, xianxia, wuxia, unreal engine 5`
**核心特征：** 仙侠武侠 / 中国元素 / 3D 渲染 / 高质量材质
**代表参数：**
- 色调：金色/白色/青色为主，仙气飘飘
- 光影：体积光、神光、能量光效
- 质感：Unreal Engine 5, ray tracing, volumetric fog
**适用场景：** 仙侠游戏、国漫角色、玄幻场景
**负面提示词：** `realistic photo, western fantasy, low poly, cartoon`

### 4.3 美漫风格 (American Comic)
**英文标识：** `american comic, marvel style, dc comic`
**核心特征：** 肌肉发达 / 线条硬朗 / 高对比 / 动态构图
**适用场景：** 超级英雄、动作场景、美式漫画
**负面提示词：** `anime, soft, realistic, watercolor`

### 4.4 赛璐璐风格 (Cel Shading)
**英文标识：** `cel shaded, flat colors, anime coloring`
**核心特征：** 平涂上色 / 清晰边界 / 少渐变 / 动画感
**适用场景：** 动画制作、游戏角色、插画
**负面提示词：** `realistic, painterly, gradient, soft shading`
